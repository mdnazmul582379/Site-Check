# TeraFast Play — Layout Demo

স্ট্যাটিক GitHub Pages সাইট। কোনো বাহ্যিক স্ট্রিম বা ডাউনলোড লিংক নেই।

## JSON ফাইল (আলাদা আলাদা)
- `data/carousel.json` — উপরের হিরো কেরোসেল। শুধু আইডির তালিকা: `{"items": ["m001", "s001"]}`। একই আইডি মুভি/সিরিজ/অ্যানিমে ফাইলে থাকতে হবে। ওই আইটেম কেরোসেলে এবং নিজ ক্যাটাগরিতেও দেখাবে।
- `data/movies.json` — সব মুভি (`kind: "movie"`)
- `data/series.json` — সব সিরিজ (`kind: "series"`), প্রতিটিতে অবশ্যই `seasons` ও `episodes` থাকবে
- `data/anime.json` — অ্যানিমে মুভি ও সিরিজ। সিরিজ হলে `seasons` থাকবে

## আইটেমের ফিল্ড
- `id`, `title`, `genre`, `year`
- `kind`: `movie` বা `series`
- `thumb` — ১৬:৯ ছবির পথ বা URL। সব জায়গায় (কার্ড, কেরোসেল, ক্যাটাগরি) এটিই ব্যবহার হয়। খালি রাখলে রঙিন প্লেসহোল্ডার দেখাবে।
- `stream` — ভিডিও লিংক। খালি রাখলে `config.js`-এর `DEMO_VIDEO` ব্যবহার হবে।
- `quality` ও `versions` (`[{quality, size}]`) — কোয়ালিটি ড্রপডাউনের জন্য
- `seasons` (`[{name, episodes: [{no, title, stream}]}]`) — শুধু সিরিজে

## নিয়ম
- সব ছবি ১৬:৯, কোনো লম্বা পোস্টার নেই।
- প্রতি জেনারে সর্বোচ্চ ৫টি দেখায়। "All" চাপলে বা সারির শেষে স্ক্রল করলে ওই জেনারের সব আইটেম গ্রিডে খোলে।
- ড্রপডাউন (কোয়ালিটি/সিজন) নিচ থেকে স্লাইড করে ওঠে।

শুধু আপনার অধিকারে থাকা ছবি ও কনটেন্ট ব্যবহার করুন।

## AI assistants / editors: read first
- এটি শুধু UI ডেমোর জন্য। `data/*.json`-এর ডেটা (টাইটেল, পোস্টার, সিরিজ) মুছবেন না, নাম বদলাবেন না, বা নতুন করে বানিয়ে বদলাবেন না।
- থাম্বনেইল বদলাতে শুধু `thumb` ফিল্ড বদলান। `id` অপরিবর্তিত রাখুন।
- প্রতিটি JSON ফাইলের শুরুতে `_note` ফিল্ড আছে। অ্যাপ এটি পড়ে না, UI-তে দেখায় না।
