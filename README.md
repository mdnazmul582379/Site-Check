# TeraFast Play — Layout Demo

স্ট্যাটিক GitHub Pages সাইট। কোনো বাহ্যিক স্ট্রিম বা ডাউনলোড লিংক নেই।

- `data/library.json` — টাইটেল, সিরিজ/সিজন/এপিসোড, জেনার, সাইজ, কোয়ালিটি
  - `thumb` = ল্যান্ডস্কেপ ছবির ইউআরএল (16:9), `poster` = পোর্ট্রেট ছবির ইউআরএল (2:3)
  - খালি রাখলে টাইটেল লেখা প্লেসহোল্ডার দেখাবে
- `config.js` — `DEMO_VIDEO` (সব এপিসোডে এই ভিডিও চলবে)

শুধু আপনার অধিকারে থাকা ছবি ও কনটেন্ট ব্যবহার করুন।
