# TeraFast Play — UI Demo

স্ট্যাটিক GitHub Pages সাইট। কোনো বাহ্যিক স্ট্রিম বা ডাউনলোড লিংক নেই।

## ডেটা ফাইল (চারটি)
- `data/carousel.json` — উপরের হিরো কেরোসেল। শুধু আইটেম আইডির তালিকা। যে আইটেম এখানে আছে, সেটি নিজ ক্যাটাগরিতেও দেখাবে।
- `data/video.json` — সব মুভি (এপিসোড ছাড়া)। অ্যানিমে মুভিও এখানে, `tags: ["anime"]` সহ।
- `data/series.json` — সব সিরিজ (এপিসোড সহ, `seasons` ও `episodes`)। অ্যানিমে সিরিজও এখানে, `tags: ["anime"]` সহ।
- `data/categories.json` — ক্যাটাগরির নাম। থাম্বনেইল খালি থাকলে কার্ড Carousel-এর আইটেমের থাম্বনেইল থেকে নেয়।

## আইটেমের ফিল্ড
- `id`, `title`, `genre`, `year`, `kind` (`movie` / `series`)
- `thumb` — ১৬:৯ ছবির URL বা পথ। কার্ড, হিরো ও ক্যাটাগরি সব এখান থেকে নেয়।
- `stream` — ভিডিও লিংক। খালি থাকলে `config.js`-এর `DEMO_VIDEO` ব্যবহার হয়।
- `quality` / `versions` — মুভির কোয়ালিটি ড্রপডাউন
- `seasons` — শুধু সিরিজে

## দেখানোর নিয়ম
- ক্যাটাগরি সেকশনে প্রথমে ৫টি কার্ড। **All ›** চাপলে ওই সেকশনের ২০টি এবং শুধু সেই সেকশন দেখাবে।
- **See more** প্রতিবার ২০টি করে যোগ করে।
- সেকশনের নিচে বাকি সেকশনগুলো লুকায়। **Back to all** দিয়ে ফেরা যায়।
- Trending হয় বেশি ক্লিক হওয়া আইটেমের ভিত্তিতে, Carousel-এর আইটেম সেখানে আসে না।

## AI assistants / editors: read first
- `data/PROTECTED.md`-এর নিয়ম মানুন। এই ডেটা মালিকের সেট করা। মুছবেন না, নাম বা `id` বদলাবেন না, নতুন করে বানাবেন না।
- কোনো পরিবর্তনের আগে মালিককে জিজ্ঞেস করুন। মালিক অনুমতি দিলে কমিট মেসেজে `[owner-approved]` লিখুন।
