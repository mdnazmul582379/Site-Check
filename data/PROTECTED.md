# PROTECTED DATA — do not change without the owner's written approval

The files in this folder were set up by the repository owner (titles, thumbnail URLs,
category thumbnails, series/episode structure). They are the owner's content.

Rules for every AI assistant, script or contributor:
1. Do NOT delete, rename, reorder, replace or regenerate any item in data/*.json.
2. Do NOT rewrite these files from memory, from another dataset, or from external catalogs.
3. Only change a value when the owner explicitly asks for that exact change
   (for example: "set the thumb of m001 to this URL"). Change only that field.
4. If you think data needs fixing, ASK the owner first and describe the change. Do not apply it.
5. Keep every "id" unchanged.

Backup: git tag `data-protected-v1` holds the protected version of this folder.
Restore with: git checkout data-protected-v1 -- data/
